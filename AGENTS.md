# Research repository guidance

This repository is **Study B — implementation evaluation** of the guardian-signed electronic promissory note research at **Mabini Colleges, Inc.** Keep population, evidence, and claims institution-specific. Read [the research skill](.agents/skills/mabini-promissory-research/SKILL.md) for substantive research work.

Current scope and evolving decisions belong in `docs/study-split.md`, `docs/protocol.md`, and the research questions. Study A's handoff guides mc-portal #740; implementation stays in mc-portal. Study B plans its approved baseline before rollout and evaluates a recorded implementation version. Neither study's draft documents establish approvals or completed research.

Never invent citations, participants, permissions, measurements, or results. Keep identifiable financial records, account identifiers, linkage keys, and actual signatures outside Git and published pages. Public examples must be synthetic or permitted disclosure-reviewed outputs. Student-session signing does not independently authenticate the guardian.

Preserve unrelated work and source provenance. Use the smallest necessary change, state material assumptions, and verify manuscript/navigation changes with `python -m mkdocs build --clean --strict` and link/render inspection. Build success does not verify research validity. When explicitly invoked, GitHub Work governs issue delivery; this research skill does not initiate other GitHub workflows, recruitment, deployment, or journal submission.
