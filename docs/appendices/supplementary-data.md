# Evidence and reproducibility plan

No study data, actual signature, participant transcript, or computed result is supplied. Public reproduction materials will use synthetic fixtures or permitted disclosure-reviewed summaries; raw identifiable records and linkage stay in approved restricted storage.

For each claim retain question ID, evidence type, source/version, artifact/instrument/protocol versions, sample and denominator, transformation or coding decision, uncertainty/limitation, and permitted evidence locator. Record code/environment and execution commands when actual analysis is implemented. Label demonstrations as synthetic so they cannot be mistaken for findings.
