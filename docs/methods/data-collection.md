# Planned collection

Finalize the protocol, event definitions, instruments, and permissions before affected collection. Dry-run with synthetic records, then collect the approved baseline before rollout. Confirm equivalent definitions and record workload, calendar, staffing, policy, and case mix.

After versioned handoff and implementation verification, conduct an approved pilot and document defect dispositions before main field collection. Collect post-rollout events, task observations, comprehension and feedback with versioned instruments. Separate observed behavior, logs, and self-report. See the [measurement plan](measurement-plan.md) and [readiness criteria](../artifact/readiness.md).
